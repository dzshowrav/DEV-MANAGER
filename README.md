# DEV MANAGER - Advanced Android System & File Tool

**DEV MANAGER** is a comprehensive, powerful, and modern Android utility application designed to elevate how you manage your device's files, storage, apps, and network connections. Built with Jetpack Compose using Material 3 guidelines, it offers a sleek, dark-themed, and highly responsive user interface.

## 🚀 Key Features

### 📁 Advanced File Manager
- **Full Navigation:** Seamlessly browse internal storage and SD cards. Includes breadcrumbs for quick navigation.
- **Rich Operations:** Create, copy, move, rename, delete, share, and view properties of files and directories.
- **Built-in Viewers:** 
  - **Text Editor:** View and edit text files effortlessly.
  - **Image Viewer:** Pan and zoom support for local images.
  - **Media Player:** Play videos and audio files internally.
- **Archive Support:** Compress files and folders into ZIP files or extract ZIP archives quickly.
- **Trash Bin:** Built-in recycle bin allowing soft deletion and restoration of files.
- **Categorized Library:** Quick access to Downloads, Images, Videos, Music, and Documents.

## 🛠 Tech Stack

- **UI Toolkit:** Jetpack Compose (Material 3)
- **Language:** Kotlin
- **Architecture:** MVVM Design Pattern with ViewModels for robust state management.
- **Asynchronous Processing:** Kotlin Coroutines & Flow for fluid interactions.
- **Storage Access:** Modern Android Storage APIs (Environment, File IO).
